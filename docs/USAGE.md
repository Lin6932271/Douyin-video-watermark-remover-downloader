# 使用文档

项目名称：**Douyin video watermark remover downloader**；应用名称：**拾影**。

**AI 开发标注：由 OpenAI Codex 开发。** 用户负责提出需求和手机端操作；安卓由用户反馈“测试可用”。iOS 当前是源码工程，未执行 Xcode 编译、签名和设备测试。

## Android：安装和下载

适用 Android 10 或更新版本。

1. 下载仓库中的 [shiying-1.0.0.apk](../dist/shiying-1.0.0.apk)。在 GitHub 文件页点击下载按钮，而不是保存网页；也可以下载整个仓库 ZIP 后从 `dist` 文件夹取出 APK。
2. 将 APK 传到手机打开安装；系统要求时允许当前文件管理器安装应用。安装完成后打开“拾影”。
3. 在抖音视频中点分享 → 复制链接。支持粘贴包含说明文字的完整分享内容。
4. 在拾影点击“粘贴” → “解析视频”。也支持从抖音系统分享菜单将文本发送到拾影。
5. 网页缺少播放数据时会打开内置网页。遇到验证或登录时由你操作；必要时播放视频数秒，再点“读取当前页面”。
6. 点击“保存视频到相册”。视频保存在系统的 `Movies/拾影/` 目录；“最近保存”可播放或分享。
7. 允许通知后可在通知栏查看进度和取消；未允许通知时可在应用前台操作。取消或失败会清理未完成的相册文件。

## iOS：先构建再安装

适用 iOS 16 或更新版本；当前仓库没有可直接安装的 IPA。

1. 将仓库下载 / 克隆到装有 Xcode 的 Mac。
2. 打开 `ios/Shiying.xcodeproj`，选择 `Shiying` Target → Signing & Capabilities → 选择自己的 Team，按需修改 Bundle Identifier。
3. 连接 iPhone，选择设备并按 Run，按手机提示处理开发者模式和开发签名信任。也可先用 iPhone Simulator 验证编译。
4. 打开拾影，粘贴分享链接 → 解析 → 必要时完成网页辅助解析 → 下载原播放视频。
5. 下载时保持应用前台。完成后在记录中选择“存入相册”，允许相册添加权限；或用“分享”保存到文件 / AirDrop。
6. 记录支持播放、分享和删除。删除本地记录不会删除已存入相册的副本。

详见 [iOS 工程说明](../ios/README.md)，包括模拟器构建和签名归档命令。

## 无水印、作者关闭下载的说明

- 应用使用公开播放地址，避免使用平台的水印下载字段，不对原文件转码或叠加水印。
- “无水印”不包括去除已经烧进画面的文字、Logo、剪辑软件水印，也不保证所有视频均有无水印地址。
- 作者关闭下载按钮，但视频仍可公开播放且返回可访问的 MP4 播放资源时，会继续尝试保存。
- 删除、私密、付费、不可播放、加密或没有返回可用资源的视频，不保证能下载。
- 仅支持单条 MP4；不包含图集、直播、HLS 合并或批量下载。

## 可选云解析

默认本机解析，不需要 API Key。只有主动启用 Firecrawl 备用解析并填入自己的 Key 时，公开分享链接才会发送到该服务；不上传本机网页登录 Cookie。Key 只保存在运行时内存，不写入源码或安装包。云解析需要你自己的服务额度，开发端未进行真实云请求验收。

## 常见问题

**解析失败 / 没有播放地址：** 使用网页辅助解析，等待网页完整加载；必要时在网页播放原视频，再读取地址。若链接失效或平台限制，换一条当前可正常播放的链接重试。

**下载地址过期：** 重新解析视频后再次下载，不复用旧签名地址。

**网页不能跳转到其他视频：** 为避免错误下载，内置网页会锁定原视频 ID。要下载另一条视频，应返回首页重新粘贴链接。

**相册保存失败：** Android 检查系统存储空间；iOS 在设置中允许相册添加权限，或使用“分享”保存到文件。

**iOS 退到后台后失败：** 本版不承诺系统挂起或强制退出后继续下载；保持应用前台，失败后重新解析。

**新构建的 APK 无法覆盖安装旧包：** 覆盖安装要求相同签名密钥。本仓库不公开密钥；自己的重新构建可能需要先卸载旧版本，卸载会清除应用本地数据。

反馈问题时提供：手机系统版本、Android WebView 版本（如适用）、分享链接、完整错误提示和复现步骤；不要公开 API Key、Cookie 或登录令牌。

## 从源码构建

### Android / Windows

准备 Python 3.9+、JDK 17，在项目根目录执行：

```powershell
$env:JAVA_HOME_17 = 'C:\Program Files\Eclipse Adoptium\jdk-17.0.17.10-hotspot'
.\build.ps1 -Setup
python .\scripts\test.py
```

首次构建需要网络下载 Google Android SDK 和测试依赖。工具缓存、签名密钥和测试原始网络证据不上传仓库。

### iOS / macOS

在 `ios` 目录执行：

```bash
bash scripts/build-ios.sh simulator
```

上述 iOS 构建命令在开发端**未执行**。生产解析脚本可单独运行：

```bash
node tests/parser.test.cjs
```
